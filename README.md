# Francis AI PPT System V1

Francis AI PPT System V1 是一套面向广告策划与提案团队的半自动 PPT 工作流系统，设计目标是将 Brief 转化为可审核的逐页文案与分镜，并将确认后的图片装配成 PPTX。关键环节保留人工确认。目前处于项目展示及运行验证阶段。

1. **从 Brief 开始。** 提供项目目标、受众和必讲内容，先看提纲和逐页文案候选。
2. **审核内容。** 逐页提出反馈，确认要保留的文字和版本。Copy Lock 可核对指定文本、段落和顺序，不能识别图片里的文字。
3. **从参考到分镜。** 只提供获准使用的参考，确认分镜和视觉方向。需要图片时，由使用者在有权限的工具中手动制作并审核。
4. **装配 PPTX。** 用已确认的图片装配演示文稿，以图片型页面为主。交付前人工检查页序、比例和可读性，不承诺对象级可编辑。
